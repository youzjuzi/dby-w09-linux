# DBY-W09 Linux

R4（2026-11-15）：维护者从空白 **16 GB 新卡**照公开文档全新安装通过，包 **`20261115-1`**（**H + R**：用户提供的 Claude SSH 核对与用户交互观察）。见[新卡结果与操作清单](docs/fresh-install.md)。第三方独立复现仍为 **U**；已有私有输入复用，提取未重做、保持原证据级别。现有 Recovery/U-Boot 未重编、未重刷；原工作卡保留作回退。

这是单机开发系统：桌面、显示／触摸、网络、音频和基础充电有各自限定范围的 H／R 记录；休眠、摄像头和传感器仍为 U。**刷写需要已解锁 Bootloader，会替换 Recovery，可能导致无法启动。安装流程未经第三方从空白卡独立验证，欢迎反馈。**

在华为 MatePad 11（DBY-W09，骁龙 865）上，从 microSD 卡运行基于主线的 Linux 和 Ubuntu ARM64。正常开机仍进入鸿蒙；手动进 Recovery 后，由 U-Boot 启动卡上的系统。日常启动无需电脑；首次准备需要 Linux 构建主机，以及所有者已解锁的设备。

这是面向单台设备／固件基线的开发系统。厂商固件、原厂镜像、面板命令数据和触摸计划数据不分发，请按链接准备自己的输入。

## 开始前你必须已经拥有

- 已解锁的 Bootloader、自己的原厂 Recovery 镜像及独立校验摘要，并保存回退副本。
- 可读取受支持运行时 FDT 的途径（ADB/root），以及自己的面板、内存私有输入。
- 若启用触摸，自己的匹配 AFE 输入及[准备指南](docs/touch-plan-preparation.md)要求的七项私有触摸计划输入。
- 由自己从自己的设备提取的固件，或固件指南说明的具有适当许可的上游替代文件。

这是开发源码工作流，不是任意平板开箱安装。APT 无冻结快照，rootfs 跨日期不保证相同。U-Boot 为十三个补丁：默认 Ubuntu／回鸿蒙／关机三项，可选加入 TWRP 成为四项。TWRP 路径要求 recovery_ramdisk 中已有匹配的 TWRP，本仓库不负责安装；载荷来源、限制及当前设备证据见 U-Boot 仓库。

触摸计划字段中的历史内部标识没有外部含义，读者无需查找对应资料。字段值修改推迟到发布后另立任务，只有生成计划表与 nt36523-thp.ko 均逐字节不变时才可修改。

## 构建 → bundle → 写卡 → 上机 → 检查

按[安装指南](docs/install.zh-CN.md)顺序执行：

1. 准备锁定上游与自己的[固件／私有输入](docs/firmware-preparation.md)，构建 U-Boot、内核、DTB 和模块。
2. 用 [bundle 工具](tools/dby-bundle/README.md)构建 p1，再构建测试或完整 [rootfs](tools/dby-bundle/rootfs/README.md)，合成新的 bundle。
3. 审阅 [SD 安装器](tools/dby-install/README.md)的 dry-run 计划，在内置 MMC 读卡口写入整张卡，向 p1 放公钥和种子。
4. 用自己的原厂镜像重打包 Recovery，仅刷 Recovery，插卡后手动进入 Recovery。
5. 检查启动、服务、显示与网络，记录证据级别，私下保存含身份信息的数据。

安装器只接受整盘 `/dev/mmcblkN` SD 卡，必须手输完整设备名确认。`install` 会清空整卡；`update`／`rollback` 配合主机备份与恢复更换 p1 设备包，保留系统与种子（上述范围内 H + R）。`seed`／`safe-mode` 已提供校验编辑和私有种子备份恢复（下述有限范围 H + R，其余 O/U），不挂载 p2。USB `/dev/sdX` 读卡器不支持。菜单与用户数据备份恢复命令尚未实现。`reinstall-system` 只重做 p2、保留 p1 与种子（完整系统 H + R），不备份且清空所有系统／用户数据。

种子口令默认明文，交互输入两次且无回显。显式 `--derived-psk` 仅适用于纯 WPA2，不适用于 WPA3/SAE 或 WPA2/WPA3 混合网络。2026-11-02，一张 SD 卡／一台平板上，`seed set` 已写入派生 PSK 并通过工具自校验，`seed restore` 已恢复原种子（H + R）。测试者的一个路由器上，计算正确的派生 PSK 无法连接，恢复原明文口令后立即连上。原因推测为 WPA3/SAE 或混合模式协商，未在路由器侧核实。2026-11-02/03，一张 SD 卡、一台平板、bundle `20261102-3`、内核 `7.2.10` 新增以下证据：`seed wizard` 在 dry-run 下拒绝两次不一致的口令且未写入；真实向导只改时区，预览仅该项变化，写入自检通过并生成备份（H）。`seed set --timezone` 两次写入后均由开机后的 `timedatectl` 确认（H）。误敲目标确认串被拒绝且未写入（H）。`safe-mode on/off` 跨启动阻止再恢复 msm、面板和触摸模块；开启时背光亮但无画面，USB 网卡与 SSH 正常（H + R）。结论不推广到其他设备或网络。`seed set` 其他项（镜像源／刷新率／软件包／替换或追加公钥）仍需真卡复验；纯 WPA2 网络上的派生 PSK 联网仍为 U（命令逻辑 O）。本次向导标签选择修复为 O，待真卡复验。

取卡前先正常关机；p2 日志未重放会报 `E_INSTALL_P2_RECOVERY`。用过的系统用 `verify --p1-only` 检查设备包；2026-11-02 一张真卡的用户复验记录覆盖 `info`、`verify --p1-only` 和 dry-run（R）；`info --full`、日志诊断及注入异常路径仍为 O，正常卡复验不等于这些路径已实测。真实卡断电／中途打断的恢复、跨内核版本更新仍未验证；bundle 目前只接受 `7.2.10`，update 不更新 p2。FAT 重命名不保证掉电安全，见[已验证流程与日志处理](docs/install.zh-CN.md#61-更新设备包不重装h--r)。

完整系统重装已有 H + R 证据（2026-11-02/03），限一张 SD 卡、一台平板、bundle `20261102-3`、内核 `7.2.10`：预览与执行成功，独立比较整个 p1 的 SHA256 前后相同，随后完整 `verify` 通过。全新系统启动，旧用户数据消失、SSH 主机密钥重新生成；保留的明文 Wi-Fi 种子自动联网，触摸正常。共享的 install 格式化／解压代码也在该卡运行。本次首次向导未卡住，不能据此认定偶发缺陷已解决。`--minimal`、`--no-readback` 和中途失败仅 O；真卡断电／中断、跨内核更新仍 U。菜单与用户数据备份恢复仍未实现（U）。

## 安全与限制

证据来自一台 HarmonyOS 4.2.0.213、Bootloader 已解锁的 DBY-W09。其他个体、固件和输入组合均为 U。保留并校验自己的原厂 Recovery 镜像以便回退。安装只替换内部 Recovery；U-Boot 另有严格检查后清理 `misc` Recovery 命令的窄例外。Linux 从卡运行。恢复出厂设置前必须先恢复原厂 Recovery。

显示与触摸共用 TDDI 控制器，不得替换其他平板的触摸固件。原生充电在一台设备上可用（H + R，2026-11-05）：充电驱动自动加载，已观察到连续充电与桌面标示；但尚未连续运行数日，长期风险未知。自然FULL/再充电、挂起、长期及多温度点仍未验证；看门狗断充后需重新插线。无快充；电脑 USB 口约 500 mA，屏幕亮时可能不够整机用。详见[充电说明](drivers/dby-chg/README.md)和[状态页](docs/status.md)。摄像头与传感器未做。硬件视频解码（Venus，需手动加载）在一台设备上 HEVC、VP9、H.264 均可解码（H，2026-11-10），但 H.264 在流结束或 seek 时固件会报错并约 3 s 后恢复，浏览器用不上，详见[状态页](docs/status.md)。

本项目是独立、非官方的设备移植工作，与 Huawei、Canonical/Ubuntu、Qualcomm 或 TeamWin 无关联，未获其认可或赞助；相关名称和商标属于各自权利人。不提供厂商固件，不保证其他设备／固件兼容。

需要已解锁的 Bootloader。刷写会替换 Recovery，修改后的镜像不匹配原 AVB 摘要；错误镜像或操作可能导致无法启动或 Recovery 无法使用。写卡会清除所选 SD 卡数据。先保留并核对自己的原厂回退镜像，恢复出厂前先还原原厂 Recovery。软件按现状提供，无担保。

## 当前使用限制

- 喇叭没有振幅或温度保护算法，限制增益不等于保护；高音量长时间播放可能损伤喇叭。内核自动加载仅在一台平板 6 次冷启动、2 次热重启通过（H + R，2026-11-17）；长期可靠性未知。
- `dby-chg` 会写 PMIC 充电寄存器 `0x1070`、`0x1643`、`0x1042`，影响充电行为。申请其三个中断时，上游 SPMI 中断控制器会写 PM8150B `0x10`、`0x13`、`0x16` 各块的中断配置寄存器；充电指示灯使用上游 PM8150L LPG 驱动。自然充满／再充电、挂起、多温度校准与长期行为仍为 U。无快充；电脑 USB 口供电时屏幕亮起可能净放电。
- s2idle 未验证。电源键守护进程停止并恢复 GNOME 设置后，通常的合盖动作为 `suspend`；实际恢复用户先前保存的值，停用前先读电源键说明。
- 蓝牙仅控制器与一只鼠标有证据，A2DP／回连未测；生成 DTB 时须自行提供私有 `local-bd-address`。
- Venus 需手动 `modprobe venus_core`；H.264 流结束／seek 可能使固件崩溃，约 3 s 恢复并丢失尾帧，浏览器用不上。固件为所有者私有输入，不分发；已有来源限制见状态页。

项目与 Huawei、HarmonyOS、MatePad、Qualcomm、Ubuntu 无关联，相关名称商标归各自所有者。逐项日期与证据边界以状态页为准。

构建喇叭模块需要所有者自备私有配置表，见[准备与构建说明](drivers/dby-tfa9874/README.md)。当前源码树不含原厂功放序列；生成头文件与含这些数据的模块不分发。
